# Стаканы

Браузерная игра на блеф для 2–8 человек. Дилер прячет фишки под стаканы,
остальные торгуются за очередь, ставят на стаканы и вскрывают их.
Всё считается на сервере, содержимое закрытых стаканов клиенту не уходит.

Версия 2.0.0

---

## Правила

### Раунд

1. **Раскладка.** Дилер прячет фишки под стаканы. Стаканов столько же, сколько игроков.
   В любой стакан можно положить ноль. Разложить нужно минимум **10% от самого большого
   стека за столом**; если у дилера меньше этой суммы — он выкладывает всё, что есть.
2. **Торги за очередь.** Каждый недилер по кругу называет ставку или пасует.
   Кто назвал больше — ходит первым, дальше по убыванию ставок, следом спасовавшие
   в порядке посадки от дилера. Если спасовали все — раунд идёт без ставок.
3. **Ставки на стаканы.** Ставят только те, кто торговался. Победитель торгов **обязан**
   поставить не меньше названной суммы (больше — можно, меньше — нет), остальные
   участники торгов ставят по желанию. Ставки открытые, их видно всем.
4. **Вскрытие.** В установленном порядке каждый недилер вскрывает один стакан.
   Последний стакан открывает дилер.
5. **Доплата.** Игрок слева от дилера доплачивает дилеру половину последнего стакана,
   округляя вверх. Не хватает фишек — не платит, стакан целиком уходит дилеру.
6. Дилером становится следующий игрок по кругу.

### Ставки на стаканы

Минимальная ставка — **20% от самого большого стека** (две минимальные ставки дилера).
Нет столько фишек — ставишь всё, что есть.

Ставки разыгрываются в момент вскрытия стакана, по очереди от первого поставившего,
и содержимое стакана по ходу уменьшается:

- фишек в стакане **больше** ставки — игрок забирает ставку обратно и ворует из стакана
  столько же, сколько поставил;
- фишек **меньше или ровно столько же** — ставка сгорает и достаётся тому,
  кто вскрыл стакан, вместе со всем содержимым.

Вдвоём ставки и торги не проводятся: дилер раскладывает, соперник вскрывает свой стакан,
последний забирает дилер.

### Что видно

Во время раунда чужие балансы заморожены на момент его начала — свой видно всегда.
Настоящие числа открываются в конце раунда, вместе с плюсами и минусами каждого.
Открытые ставки и вскрытые стаканы видны сразу, это и есть вся информация для расчёта.

### Конец игры

Партия заканчивается, когда кто-то обнуляется. Места распределяются по количеству
фишек у оставшихся, банкрот забирает последнее.

### Время и отключения

На каждое действие даётся **60 секунд**. Не успел — сервер играет за тебя:
раскладывает случайно по минимуму, пасует в торгах, вскрывает случайный стакан.

На возвращение в игру после обрыва связи есть **90 секунд**. Не вернулся —
выбываешь, а твои фишки делятся между оставшимися.

## Запуск

```bash
npm install
npm start
```

Открыть http://localhost:3000. Чтобы проверить вдвоём в одном браузере, открой вторую
вкладку в режиме инкогнито: обычные вкладки делят localStorage и получат один id.

Переменные окружения для отладки: `TURN_MS` (время на ход), `RECONNECT_MS`, `PORT`.

## Деплой на Render (бесплатно, без карты)

1. Залей файлы в репозиторий на GitHub — `package.json` должен лежать **в корне**,
   не внутри вложенной папки.
2. render.com → регистрация через GitHub → **New → Web Service** → выбрать репозиторий.
3. Language **Node**, Build Command `npm install`, Start Command `npm start`,
   Instance Type **Free**.
4. Через пару минут получишь адрес вида `https://cups-xxxx.onrender.com` —
   это ссылка для игроков.

Порт берётся из `process.env.PORT`, WebSocket работает по тому же адресу.

Если репозиторий получился с вложенной папкой, не перезаливай: Settings →
Build & Deploy → **Root Directory** → имя папки.

### Про бесплатный тариф

Сервис засыпает после 15 минут без запросов и просыпается примерно за минуту.
Лимит — 750 часов в месяц на воркспейс, этого хватает на круглосуточную работу.
Чтобы не засыпал, повесь бесплатный монитор UptimeRobot на `/healthz`
с интервалом 5 минут.

Состояние комнат живёт в памяти: редеплой или засыпание стирают активные партии.

Альтернативы без сна: **Koyeb** (просит карту), **Fly.io** (нужен flyctl и Dockerfile),
**Northflank** (free-tier работает 24/7).

## Структура

```
server.js          вся логика игры, комнаты, таймеры, WebSocket
public/index.html  клиент целиком: стол, анимации, панель действий
package.json
```

Клиент подтягивает шрифты Unbounded и Golos Text с Google Fonts, при недоступности
откатывается на системный. Стаканы, фишки и стол нарисованы SVG и CSS,
картинок нет.

## Интерфейс

Игроки сидят по краям овального стола, ты всегда снизу. Дилер помечен белой
фишкой D, тот, чей ход, подсвечен. Стаканы стоят по центру, под ними висят
открытые ставки. Выигранные фишки перелетают от стакана к месту игрока.
Полоса под сообщением — оставшееся время хода.

Зайти в комнату можно наблюдателем, а также любой, кто пришёл после начала партии,
садится смотреть и попадает за стол в следующей игре.
