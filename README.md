# Стаканы — мультиплеер

Структура:

```
cups/
  server.js          # сервер: комнаты, вся логика игры
  package.json
  public/index.html  # клиент
```

Игроки заходят по коду комнаты из 4 символов или по ссылке `?room=КОД`.
Логика считается на сервере, содержимое закрытых стаканов клиенту не отправляется —
подсмотреть через DevTools нельзя.

## Локальный запуск

```bash
npm install
npm start
```

Открыть http://localhost:3000. Чтобы проверить вдвоём-втроём — открой несколько
вкладок в режиме инкогнито (обычные вкладки делят localStorage и получат один id).

## Деплой на Render (бесплатно, без карты)

1. Залей папку в репозиторий на GitHub (в `.gitignore` уже есть `node_modules`).
2. Зарегистрируйся на render.com через GitHub.
3. **New → Web Service** → выбери репозиторий.
4. Настройки:
   - Language: **Node**
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: **Free**
5. **Deploy**. Через пару минут получишь адрес вида
   `https://cups-xxxx.onrender.com` — это и есть ссылка для игроков.

Порт брать из `process.env.PORT` уже настроено, ничего править не нужно.
WebSocket на Render работает по тому же адресу, отдельной настройки нет.

### Про бесплатный тариф

Бесплатный сервис засыпает после 15 минут без запросов и просыпается на следующем
запросе примерно за минуту. На воркспейс даётся 750 часов работы в месяц.
Для игры это значит: первый заходящий ждёт ~30–60 секунд, дальше всё быстро.

Чтобы сервис не засыпал, повесь бесплатный монитор на UptimeRobot:
Add New Monitor → HTTP(s) → URL `https://твой-адрес.onrender.com/healthz` → интервал 5 минут.
750 часов хватает на круглосуточную работу одного сервиса.

Важно: состояние комнат лежит в памяти. Засыпание, редеплой или перезапуск
стирают активные игры — доигрывать придётся заново.

### Альтернативы

- **Koyeb** — бесплатный инстанс не засыпает, WebSocket поддерживается нативно, но при регистрации просят карту.
- **Fly.io** — 3 машины shared-cpu-1x в бесплатном лимите, нужен `flyctl` и Dockerfile.
- **Northflank** — free-tier приложения работают 24/7.

Render проще всего для старта: карта не нужна, деплой из репозитория в три клика.

## Оформление

Клиент подтягивает шрифты Unbounded и Golos Text с Google Fonts. Если они не
загрузятся, всё переключится на системный шрифт — вёрстка не поедет.
Стаканы и стопки фишек нарисованы SVG прямо в разметке, картинок нет,
грузить нечего.

## Что стоит знать про игру

- 3–8 игроков, начинать может только создатель комнаты.
- Если игрок отключился во время партии, он остаётся в игре со своими фишками
  и возвращается по той же ссылке (id хранится в localStorage браузера).
- Если отключился дилер, раздача ждёт его возвращения — принудительного скипа нет.
- «Следующий раунд» может нажать дилер или создатель комнаты.
